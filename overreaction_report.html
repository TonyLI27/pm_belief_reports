个人过度反应、整体反应不足？——β₁：总体 vs 个体

用 Polymarket 真钱信念复刻 Bordalo、Gennaioli、Ma、Shleifer（AER 2020）。issue #6、 #7、#8。 含全部表格和图 1、2、4、5 的完整版在 overreaction_report_full.html。

预测误差 FE = xm − bt　　信念修正 FR = bt − bt−1　　FE = β₀ + β₁·FR + ε：β₁ > 0 反应不足，< 0 过度反应
  • 总体（圆点）：先把一组人的信念聚合成一条序列（按人头平均，或按投入的钱加权），再回归，对应 BGMS 的「共识」。标准误 Newey–West，悬停另给按会议聚类的 wild bootstrap p。
  • 个体（菱形）：每个钱包自己的信念，所有钱包放在一起回归。标准误按钱包 × 日期双向聚类。
  • 信念：会议 m 的所有相关问题放在一起，按投入的钱加权；持 No 的钱均分到其他互斥选项（#7 第三版）。
  • 距公布日 h = 公布日 − t。原窗口从上一次会议公布之后开始，最长 49 天；31–90 天超出原窗口的部分只用决议梯子算信念，因为那时「会前降过息吗」还会被上一次会议触发。修正只在同一口径内计算。
  • 只用有成交的天：钱包当天对这次会议的相关问题至少有一笔成交（周频 = 这一周内至少一笔）。成交日里仍有 53.5% 的修正为 0，例如只在原有选项上加仓。总体回归不受这个筛选影响。
  • 周频：只用每周五，修正取 7 天差。
  • β₁ ≈ −0.5 正是「信念 = 真值 + 每天独立的噪声」时的机械结果，读个体结果时要记住这一点（完整版表 2、表 4 有滞后修正的诊断）。
