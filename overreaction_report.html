个人过度反应、整体反应不足？——β₁：总体 vs 个体

用 Polymarket 真钱信念复刻 Bordalo、Gennaioli、Ma、Shleifer（AER 2020）。issue #6、 #7、#8、#9。 含全部表格和图 1、2、4、5 的完整版在 overreaction_report_full.html。

预测误差 FE = xm − bt　　信念修正 FR = bt − bt−1　　FE = β₀ + β₁·FR + ε：β₁ > 0 反应不足，< 0 过度反应
  • 总体（圆点）：先把一组人的信念聚合成一条序列（按人头平均，或按投入的钱加权），再回归，对应 BGMS 的「共识」。标准误 Newey–West，悬停另给按会议聚类的 wild bootstrap p。
  • 个体（菱形）：每个钱包自己的信念，所有钱包放在一起回归。标准误按钱包 × 日期双向聚类。
  • 信念：会议 m 的所有相关问题放在一起，按投入的钱加权；持 No 的钱均分到其他互斥选项（#7 第三版）。
  • 距公布日 h = 公布日 − t。原窗口从上一次会议公布之后开始，最长 49 天；31–90 天超出原窗口的部分只用决议梯子算信念，因为那时「会前降过息吗」还会被上一次会议触发。修正只在同一口径内计算。
  • 只用有成交的天：钱包当天对这次会议的相关问题至少有一笔成交（周频 = 这一周内至少一笔）。成交日里仍有 53.5% 的修正为 0，例如只在原有选项上加仓。总体回归不受这个筛选影响。
  • 周频：只用每周五，修正取 7 天差。
  • β₁ ≈ −0.5 正是「信念 = 真值 + 每天独立的噪声」时的机械结果，读个体结果时要记住这一点（完整版表 2、表 4 有滞后修正的诊断）。下面两组筛选器用来去噪（#9），都只作用于个体。
  • 只高确定性：用同一套成本分配算每个钱包信念的加权标准差 sd（钱在各结果上摊得越开，sd 越大）。同一会议、同一天的钱包里，sd ≤ 中位数的记为高确定性，按 t 当天分组。 只押单一结果的钱包 sd = 0，并列都算高确定性，所以这一组占全部观测的 70.7%。买 No 或阈值问题会机械地把钱摊开，sd 偏大，所以这个指标部分反映的是用什么合约下注。
  • 跨会议工具变量（仿 BGMS 2020 处理测量误差的做法）：在较近会议 m 的窗口里的某天，同一钱包也持有较远会议 m+1 的仓位。 被解释的是 m+1 的预测误差，它的修正用同一钱包同一天对 m 的修正作工具。m 信念里的噪声不进入 m+1 的误差，所以噪声造成的 −0.5 被去掉。 这些观测距 m+1 公布日都在 42 天以上，所以只有含 31–90 天的组合有估计；m+1 的信念在这一段只用决议梯子。悬停另给同样本不校准的 β₁、简约式系数和第一阶段 F。
