个人过度反应、整体反应不足？——用 Polymarket 真钱信念复刻 BGMS（AER 2020）

issue #6；数据面板来自 #1，连续信念与分组来自 #3。时间一律 UTC。

一、这页在做什么

Bordalo、Gennaioli、Ma、Shleifer（AER 2020，下称 BGMS）用专业预测者问卷发现：每个人单独看是过度反应（上调预测之后往往发现调过头）， 平均成「共识」看是反应不足（共识上调之后实际值还更高）。他们在联邦基金利率上的数字：共识 β₁ = 0.61（s.e. 0.23），个体 β₁ = 0.15（0.09）。

这里用 Polymarket 上每个钱包的真钱仓位复刻这件事。预测 = 钱包 i 对会议 m 的连续信念 b（bp）；实际 = 会议 m 的真实变动 xm；

预测误差 FE = xm − bt　　信念修正 FR = bt − bt−1　　回归 FE = β₀ + β₁·FR + ε：β₁ > 0 反应不足，< 0 过度反应
  • 信念口径：把和会议 m 有关的所有问题（决议梯子 5 个选项 + 「会前降过息吗 / 加过息吗」）放在一起（用户 2026-10-09）， 对每个可能结果算「他押在它上面的钱有多少」（每张票按自己的平均买入成本计；持 No 的票 = 持其他选项的 Yes，钱按当天市场概率分摊到它不覆盖的结果上），按投入的钱加权平均（#7 第二版，用户 2026-10-10）。 和前两版的区别：#6 按到手份额加权，便宜的降息彩票一块钱能买几十份，信念被机械地拉向降息，全市场加总后恒等于结果值的简单平均（−12.5bp）；#7 第一版按花的钱加权但 No 票在每个赚钱的结果上各记全额，「不会加息」这种 0.9 美元一份、近乎无风险的票被当成大额降息押注；第二版把 No 按市场概率折算。前两版的结果保留为对照列。
  • 窗口：上一次会议公布日之后 → 本次公布日之前（约 6 周）。在那之前「会前降过息吗」还可能被上一次会议触发，不只取决于这次会议。
  • 频率：主结果日频（每天 23:59 UTC 收盘仓位，没成交的日子仓位沿用）；周频（每周五）整套再做一遍。
  • 两种聚合：按人头平均 Bmean（BGMS 的共识定义）；按投入的钱加权 Bpw = ΣiΣj 投入ij·xj / ΣiΣj 投入ij（先在钱包内对冲再加总，等价于按每人投入总额加权）。
  • 四组账户（互斥，按顺序归类）：机构 = 累计盈亏 ≥ 10 万美元；散户 = 累计交易额 ≤ 1,000 且 |盈亏| ≤ 100；做市商 = 利率市场挂单占比 > 80% 且 ≥ 200 条腿；对冲需求 = 累计盈亏后 1%（原「大额亏损户」）。

四、回归：预测误差对信念修正

表 2　总体层面 (R1)

xm − Bt = β₀ + β₁ (Bt − Bt−1) + ε。β₁ > 0 反应不足，< 0 过度反应。对照 BGMS 联邦基金利率共识 β₁ = 0.61（s.e. 0.23）。 标准误：Newey–West（日频带宽 5 天，周频 4 周）；按会议聚类；按会议聚类的 wild bootstrap（9,999 次）p 值 —— 只有 21 个会议，看最后这个最稳。加粗 = wild bootstrap p < 0.05。

读表前先看一个数：β₁ ≈ −0.5。如果信念 = 真值 + 一个每天独立的噪声，那么 cov(x − Bt, Bt − Bt−1) = −var(噪声)、var(Bt − Bt−1) = 2·var(噪声)，β₁ 机械地等于 −0.5，和「过度反应」无关。 所以每个设定都多报一行「右边变量 = FRt−1」：把修正换成上一期的，x − Bt 和 Bt−1 − Bt−2 不再共用 Bt，纯噪声下应为 0；真的过度反应（修正之后继续往回走）才会保持为负。
